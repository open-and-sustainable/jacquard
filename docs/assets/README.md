# Documentation assets

Store project images in `images/`:

- `images/jacquard-logo.png`: project logo, with transparency where appropriate.
- `images/jacquard-favicon.ico`: browser icon.

The paths are configured in `docs/_config.yml`. The layout displays each image
only if its file exists. Jacquard-specific filenames keep the theme's bundled
artwork out of the project header. Documentation source and image files are
published by the Documentation Pages workflow.

The main accent color is indigo, configured by `nav_background_color` in
`docs/_config.yml`. Navigation, headings, links, and informational callouts use
the indigo palette.
